初次提交：温度测控仿真系统完整实现

内容：
- Arduino UNO 固件（LCD1602 4位模式 + BMP180 I2C 温度读取 + 电机控制 + 串口通信）
- PC 上位机（Python3 + Tkinter + pyserial，含发送/接收窗口与串口开关）
- Proteus 工程（已注入编译好的固件，打开按 F12 即可仿真）
- 辅助脚本（固件编译注入、温度设定、串口配置、报告生成）
- 详细文档与踩坑记录
- 最终报告与仿真截图

关键实现要点：
1. Proteus 仿真 ATmega328P 时加载的是工程内嵌的
   FIRMWARE/ATmega328P/Debug/Debug.elf，仅修改元件的 Program File 属性无效，
   必须重新编译并把产物注入该文件
2. AVR 的 printf 不支持 %f，温度需改用整数运算（单位 0.1 度），否则显示乱码
3. BMP180 温度设定值 SETPOINT2 的属性格式为 INT,10,100，
   写入小数会导致 Proteus 打开工程时卡死
4. I2C 器件探测采用"写值再读回校验"，比仅依赖 ACK 返回值可靠
5. pyserial 的 list_ports 无法枚举 VSPD/com0com 虚拟串口，需改用系统 API 枚举
6. 工程内部文件 ROOT.CDB 为 latin-1/二进制混合编码，路径中不能含中文
