## 三、虚拟串口（上位机通信必需，目前未安装）

### 问题说明
工程里 **COMPIM (P1) 固定使用 COM1**，而本机 COM1 是**物理串口**。
需要做一对虚拟串口把 Proteus 和上位机连起来。本机现状：

| 端口 | 用途 |
|---|---|
| COM1 | 物理串口（主板自带） |
| COM2 | **空闲**（推荐作为配对端） |
| COM3–COM10 | 蓝牙虚拟串口 |

### 方案 A：安装 VSPD（题目指定）
1. 下载：https://www.eltima.com/products/vspdxp/
2. 安装后新建一对串口：**COM1 ↔ COM2**
   - 若 VSPD 报“COM1 已被占用”，说明物理串口占了号，
     **改用 COM11 ↔ COM12**，然后做第 3 步改 COMPIM 端口。
3. 若用了 COM11/COM12：双击原理图右侧 **P1 (COMPIM)**，
   把 **Physical Port** 改成 **COM11**（波特率保持 9600）。

### 方案 B：安装 com0com（免费开源，推荐）
1. 下载：https://sourceforge.net/projects/com0com/files/
2. 安装后打开 **Setup Command Prompt**，执行：
   ```
   install PortName=COM1 PortName=COM2
   ```
   或用 GUI 版 com0com，在界面里点 “Add Pair”。
3. 同样地，若 COM1 冲突就改用 COM11/COM12 并同步修改 COMPIM。

> 两个方案任选其一，装好后**重启一次**，再到第四步。

## 五、如果要修改固件代码

改了 `code\TemCtrlSys\TemCtrlSys.ino` 之后，**必须重新编译并注入工程**，
否则 Proteus 跑的还是旧固件。执行：

```bat
python "G:\deepseek-harness\default-workspace\A测试工作区\build_firmware.py"
```

脚本会：
1. 用 **Proteus 自带的 AVR 工具链**（`avr-g++ 4.9.2`）编译 sketch、core、库；
2. 生成 `Debug.elf`；
3. 把 `Debug.elf` 注入 `TemCtrlSys.pdsprj` 的
   `FIRMWARE/ATmega328P/Debug/Debug.elf` —— **这一步是关键**，
   因为 Proteus 仿真 ATmega328P 时加载的是工程内嵌的这个文件，
   光改元件的 Program File 属性没用。

## 六、踩过的坑（避免重复）

| 现象 | 原因 | 解决 |
|---|---|---|
| LCD 全黑/无显示 | 工程内嵌的 `Debug.elf` 是 2021 年的空模板（`setup()`/`loop()` 都空） | 用 `build_firmware.py` 重新编译并注入 |
| LCD 显示 `TEMP:?C` 或乱码 | AVR 的 `printf` **不支持 `%f`**，`snprintf("%.1f")` 输出垃圾 | 已改为整数运算（0.1 ℃ 为单位） |
| 温度显示 0.0 | 旧固件的 I2C 地址探测不可靠 | 已改用「写回读校验」探测，锁定 0x77 |
| 改 Program File 无效 | Proteus 优先使用工程内嵌的 `FIRMWARE/.../Debug.elf` | 必须注入该文件 |
| 固件路径不能带中文 | 工程内 `ROOT.CDB` 是 latin-1/二进制混合编码 | 编译输出放在 `G:\dsh_at\`（纯 ASCII） |
| `.ino` 里中文注释导致编译失败 | 工程内嵌文件按 ASCII 处理 | 工程内的 `main.ino` 用英文注释 |

## 七、引脚与协议对照（供核对）

| 器件 | 引脚 | Arduino |
|---|---|---|
| LCD1602 (LM016L) | RS / E | D12 / D11 |
| LCD1602 数据 | D4 D5 D6 D7 | D5 / D4 / D3 / D2 |
| BMP180 | SDA / SCL | A4 (PC4) / A5 (PC5) |
| 电机驱动 | 基极（经 4.7k） | D7 (IO7) |
| COMPIM | RXD / TXD | PD0 / PD1 |

| 方向 | 内容 |
|---|---|
| PC → Arduino | `23009290073\r\n`（每 200 ms 重发） |
| Arduino → PC | `TEMP:30.0C\r\n`（每 200 ms 回传） |
| 串口参数 | 9600, 8, N, 1 |
