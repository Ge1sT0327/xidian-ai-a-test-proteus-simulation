## 二、装虚拟串口

### 2.1 为什么需要虚拟串口

Proteus 里的 **COMPIM** 组件要绑定一个真实的 COM 口，上位机也要打开一个 COM 口。
这两个口必须**成对互通**，才能实现「Proteus 里的 Arduino ↔ PC 上位机」通信。

物理上我们没有两个接在一起的串口，所以用软件造一对虚拟串口。

### 2.2 本机端口占用排查

先看清楚哪些端口能用：

```powershell
[System.IO.Ports.SerialPort]::GetPortNames()
```

典型结果与含义：

| 端口 | 占用情况 |
|---|---|
| COM1 | 主板物理串口 |
| COM3 ~ COM10 | 蓝牙虚拟串口（很多笔记本默认就有 8 个） |
| **COM11 / COM12** | **空闲 ✅ 推荐用这一对** |

### 2.3 用 VSPD 建串口对

1. **以管理员身份**运行 `vspdconfig.exe`
   （普通权限运行会提示 *The requested operation requires elevation*）
2. 「端口一」选 **COM11**，「端口二」选 **COM12**
   > ⚠️ 不要两个都选同一个端口，会出现 `no port selected` 且建不出来
   > ⚠️ 不要用 COM1（物理串口），容易冲突
3. 点「添加端口」
4. 状态栏出现 `Pair COM11 <-> COM12 created successfully` 即成功

### 2.4 验证

```powershell
# 应该能看到 VSerial_0=COM11, VSerial_1=COM12
Get-ItemProperty "HKLM:\HARDWARE\DEVICEMAP\SERIALCOMM"

# 驱动服务应为 Running
Get-Service evserial
```

Python 双向回环测试：

```python
import serial, time
a = serial.Serial('COM11', 9600, timeout=0.5)
b = serial.Serial('COM12', 9600, timeout=0.5)
time.sleep(0.3)
a.write(b'hello\r\n'); a.flush()
time.sleep(0.3)
print(b.read(64))        # 应输出 b'hello\r\n'
a.close(); b.close()
```

> 💡 建好串口对之后，**VSPD 主程序可以关掉**，驱动服务会继续运行，虚拟串口依然有效。

### 2.5 用 com0com 代替（免费开源）

```
install PortName=COM11 PortName=COM12
```

在 com0com 的 Setup Command Prompt 里执行，或用 GUI 版点 "Add Pair"。

## 三、Proteus 侧配置

### 3.1 把 COMPIM 指到 COM11

**方法 A：界面改（推荐）**

双击原理图右侧的 **P1 (COMPIM)**，把 `Physical Port` 改成 **COM11**，
波特率保持 **9600**。

**方法 B：脚本改**

```bat
python tools\set_compim_port.py COM11
```

> 原理：`.pdsprj` 是 zip，里面的 `ROOT.CDB` 是文本，
> COMPIM 的端口存为 `{P_PORT=COM11}`，脚本只替换这一个字段。

### 3.2 把固件写进工程

**这是最关键的一步**，详见 README 第五节的「坑 1」。

```bat
python tools\build_firmware.py
```

脚本会自动：

1. 把 `.ino` 转成 `.cpp`
2. 编译 sketch（需要 `LiquidCrystal` 和 `Wire` 库）
3. 编译 Arduino core
4. 链接成 `Debug.elf`
5. **注入** `.pdsprj` 的 `FIRMWARE/ATmega328P/Debug/Debug.elf`

### 3.3 运行仿真

打开 `.pdsprj`，按 **F12**（或点左下角 ▶）。

判断仿真是否真的在跑：看窗口底部状态栏，应显示

```
ANIMATING: 00:00:xx.xxxxxx (CPU load xx%)
```

如果是 `PAUSED: ...` 说明还没开始跑；如果 LCD 全黑而消息数一直停在个位数，
说明固件没进去（回到 3.2）。

## 四、PC 上位机

### 4.1 运行

```bat
cd code\pc
pip install pyserial
python TempMonitor.py
```

### 4.2 操作

1. 「串口」下拉框选 **COM12**（与 COMPIM 的 COM11 配对的那一端）
2. 点「打开串口」，状态变绿
3. 勾选「自动周期发送」后，发送窗口每 200 ms 发一次学号
4. 接收窗口应出现 `TEMP:30.0C` 这类数据

### 4.3 收不到数据怎么排查

按顺序检查：

1. Proteus 是否**正在运行**（状态栏是不是 `ANIMATING`）
2. COMPIM 的端口是不是 **COM11**，上位机是不是 **COM12**（**不能选同一个**）
3. 两端波特率是否都是 **9600**
4. 固件是否真的注入了（README 坑 1）
5. 用自检工具：

```bat
python serial_check.py COM12
```

## 五、改温度并截图

### 5.1 改温度

**方式 A：脚本（推荐）**

```bat
python tools\set_sensor.py 34
```

然后**重新打开工程**、按 F12。

> ⚠️ 参数**必须是整数**。传 `34.0` 会让 Proteus 打开工程时卡死，见 README 坑 4。

**方式 B：界面**

仿真运行时双击 **U2 (BMP180)**，面板上有 `▲ / ▼` 按钮。左右各一对：

- 左边一对调 **气压**（hPa）
- 右边一对调 **温度**（℃）

> 实测：仿真运行时这些按钮**经常不响应**点击。所以推荐方式 A。

### 5.2 截图要求

一张截图里必须**同时**看清 5 项：

| # | 内容 | 在哪看 |
|---|---|---|
| 1 | 完整学号 | 上位机发送窗口 |
| 2 | 传感器温度 | Proteus 里 BMP180 面板 |
| 3 | 学号 + 温度 | Proteus 里 LCD |
| 4 | 回传温度 | 上位机接收窗口 |
| 5 | 电机状态 | 上位机「直流电机状态」+ Proteus 里电机 |

**摆窗口建议**：把上位机窗口放屏幕左侧，Proteus 放右侧，然后全屏截图。
2560×1440 的全屏截图嵌进 Word 后仍能看清数字。

**要采两张**：

- 高于阈值（如 31.0 ℃，阈值 30.0）→ 电机**转动**
- 低于阈值（如 29.0 ℃）→ 电机**停止**

### 5.3 验证三处温度一致

截图前务必确认：

```
BMP180 面板显示 31.0
LCD 显示         TEMP: 31.0C
上位机接收窗口    TEMP:31.0C
上位机当前温度    31.0 ℃
```

四处一致才行。不一致说明有环节没对上（通常是固件没更新）。

## 六、生成报告

```bat
python tools\make_report.py
```

会按 `doc\报告模板.docx` 的结构生成报告，并自动嵌入：

- 系统框图（`screenshots\sys_block.png`）
- 两张仿真截图（`high_temp.png` / `low_temp.png`）
- 两段源码（直接读 `code\` 下的文件）

导 PDF：用 Word / WPS 另存为 PDF，文件名按题目要求：

```
学号_姓名_学院_线上A测报告.pdf
```

## 七、常见问题速查

| 现象 | 原因 | 解决 |
|---|---|---|
| LCD 全黑，消息数不动 | 内嵌固件是空模板 | 跑 `build_firmware.py` 注入固件 |
| LCD 显示 `TEMP:?C` 乱码 | AVR printf 不支持 `%f` | 温度改整数运算 |
| 温度一直 0.0 | I2C 地址探测不可靠 | 用写回读校验探测（0x77） |
| 打开 .pdsprj 卡死无窗口 | `SETPOINT2` 写了小数 | 恢复备份，改回整数 |
| 下拉框里没有 COM11/COM12 | pyserial 枚举漏了虚拟口 | 改用系统 API 枚举 |
| 上位机收不到数据 | 端口选错 / 仿真没跑 / 固件没进 | 见 4.3 排查 |
| Proteus 打开报 Fatal Error | 工程内部被写入中文路径 | 用纯 ASCII 路径重新编译 |
| VSPD 点不动/点不了 | 它以管理员权限运行 | 手动建串口对 |
| 仿真运行时点 BMP180 按钮没反应 | Proteus 常态 | 用 `set_sensor.py` 改 |
